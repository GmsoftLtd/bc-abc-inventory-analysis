# ABC History

Search for **ABC History**. Every time classes are applied, from the worksheet or by the job, one history entry is created with one line per item in the preview.

## The list

| Field | Meaning |
|---|---|
| Entry No. | Sequential number. |
| Model | The model that was applied. |
| Start Date, End Date | The period that was calculated. |
| Items Count | Number of lines in the run. |
| Total Amount | Sum of the values in the run. |
| Created By, Created At | Who applied, and when. |

Choose **Open** to see the card. Entries can be deleted from the list by administrators; deleting an entry removes its lines.

## The card

The card repeats the header fields and adds **Statistics (from lines)**: amount, count and share of amount for classes A, B and C, calculated from the lines. Class D lines, which have no value, are counted with C.

The **Lines** part lists every item with its value, share, cumulative share and class, sorted by class.

**Export Lines to Excel** downloads the lines of this entry.

## What history is used for

- **Audit**: you can see what an item's class was at any past run.
- The **Item Movement report** compares the class on the item today with the class in the last run applied on or before a date you choose.
- The daily job writes six entries per day. Delete old entries occasionally if the list grows large; nothing else depends on them.
