ABC Inventory Analysis - Validation Guide

Publisher GMSOFT LIMITED · App ID fed0d995-8c8d-4fda-bd16-e10d112171fb · Version 1.2.1.0 · Free app, no licence or trial logic

1. What the app does

Ranks items by one of six models (Revenue, Gross Profit, Value / COGS, Usage Value, GMROII, Pick Frequency), assigns each item an ABC class from the cumulative share of value, and writes the class to the Item and Stockkeeping Unit. Optionally sets the physical inventory counting period code from the class. All data stays inside Business Central.

2. Prerequisites

  • Business Central online, version 27 or later. Any demo company with posted sales works; CRONUS is sufficient.
  • No external accounts, keys or services are required.
  • Assign the permission set GSO ABC ADMIN (caption "ABC Inventory - Administrator") to the test user. The second permission set, GSO ABC USER, covers everyday use without setup rights.

3. Where to find the pages

Use Tell me (Alt+Q) and type "ABC". The pages are also grouped under ABC Inventory in the Business Manager, Order Processor and Warehouse Basic role centers. Context-sensitive help (F1) opens https://gmsoftdynamics.com/apps/free/abc-inventory-analysis/docs/.

4. Key usage scenario (about 5 minutes)

#StepExpected result
1Open ABC Analysis Setup.Record exists with defaults: A 80 %, B 95 %, 365 days for every model; Installed Version 1.2.1.0. The DEFAULT counting policy was created on install.
2Open ABC Worksheet, choose Calculate, model Revenue, Start Date 01/01/2020, End Date blank, OK.Lines appear sorted by Value descending with Value %, Cumulative % and class A/B/C; items without sales show class D. The Statistics FactBox shows counts and amounts per class.
3Choose Export to Excel.A workbook with sheets Preview and Statistics downloads.
4Choose Apply to Items/SKUs, confirm.Message "Classes applied: n items updated". Setup field Last Run is filled.
5Open the Item Card of the first worksheet line (CRONUS UK: 1896-S ATHENS Desk), group ABC Classification.ABC Class (Revenue) = A and ABC Last Calculated (Revenue) = now. Other models blank until applied.
6Open ABC History.One entry for Revenue with Items Count and Total Amount. Open it: lines per item and class statistics.
7Open ABC Counting Policies, policy DEFAULT, edit the Revenue lines: A = MONTHLY, B = QUARTERLY, C = YEARLY (create these under Phys. Invt. Counting Periods if the company has none). In setup turn on Update Phys. Invt. Counting Codes. Repeat step 2 and 4.Item 1896-S now has Phys Invt Counting Period Code = MONTHLY (Item Card, Inventory group).
8In setup choose Create/Enable Job Queue.Message with the job queue entry ID. Job Queue Entries shows an entry for codeunit GSO ABC Analysis Job, recurring daily, status Ready.
9Run the reports ABC Inventory Analysis, ABC Class Distribution, ABC Detail by Class (Revenue, Start Date 01/01/2020), ABC Multi-Model Comparison, ABC Item Movement (Compare to Date = today) and ABC Exception Report.Each report previews without error. Detail by Class lists items by value with Cumulative % rising to 100.

5. Optional checks

  • Set Exclude from ABC on an item, recalculate: the item is no longer listed.
  • Set ABC Manual Override on an item, apply again: its class and timestamp do not change, the item still appears in History.
  • Turn off Class Zero Consumption as D in setup, recalculate: items without sales are no longer listed.
  • Switch the language to Greek or Italian: all captions and messages are translated.

6. Uninstall

Uninstalling removes all app pages and reports. Item and SKU fields added by the app are removed with the app data; no standard data is modified except the Phys Invt Counting Period Code when step 7 was performed.
