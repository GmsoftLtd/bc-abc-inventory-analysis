## 1. Logos

### Requirements

#### Logo Sizes (All PNG format, transparent background)

**Small Logo**: 48×48 pixels
- Filename: `abc-inventory-48.png`
- Use: AppSource search results, mobile view
- Guidelines:
  - Simple, recognizable icon
  - No text if possible
  - High contrast
  - Transparent background

**Medium Logo**: 90×90 pixels
- Filename: `abc-inventory-90.png`
- Use: App details page sidebar
- Guidelines:
  - Can include small text/brand name
  - Clear at small sizes
  - Transparent background

**Large Logo**: 216×216 pixels
- Filename: `abc-inventory-216.png`
- Use: Featured apps, promotional materials
- Guidelines:
  - Full branding allowed
  - High quality, sharp edges
  - Transparent background
  - Consider square crop area

**Wide Logo**: 255×115 pixels
- Filename: `abc-inventory-wide.png`
- Use: AppSource banners, featured sections
- Guidelines:
  - Horizontal layout
  - Brand name + icon
  - Transparent background

### Design Guidelines

**Color Palette**:
- Primary: Blue (#0078D4) - Business Central brand alignment
- Secondary: Green (#107C10) - Growth/optimization
- Accent: Orange (#FF8C00) - ABC classification
- Text: Dark gray (#323130)

**Icon Suggestions**:
- Bar chart with A/B/C labels
- Grid/matrix representation
- Ascending bars (Pareto principle)
- Inventory box with classification tags

### File Specifications
```
Format: PNG-24
Color Mode: RGB
Transparency: Yes (alpha channel)
Compression: Optimize for web
DPI: 72 (screen)
Max file size: 512 KB per file
```

## 2. Screenshots

### Requirements
- **Number**: 3-5 screenshots (5 recommended)
- **Size**: 1280×720 pixels (16:9 aspect ratio)
- **Format**: PNG or JPEG
- **Quality**: High resolution, clear text

**Tips**:

**Filename**: `05-parameters-setup.png`

- ABC Worksheet Parameters page

- Location filters
- Language selection

**Tips**:
- Show configurability
- Professional UI
- User-friendly settings
- Clear labels and help text

### Screenshot Best Practices

**Do**:
- Use realistic but clean demo data
- Show key features clearly
- Include some data (not empty screens)
- Use consistent branding
- Ensure high readability
- Show the app in context (BC interface)
- Include subtle annotations if needed
- Use the same BC version throughout

**Don't**:
- Show empty pages or "No data" messages
- Include real customer data
- Use low resolution images
- Show error messages
- Include personal information
- Use cluttered or messy data
- Show debug/development modes
- Include unfinished features

### File Specifications
```
Dimensions: 1280×720 pixels (exactly)
Format: PNG (preferred) or JPEG
Color Mode: RGB
DPI: 96 (screen)
Max file size: 1024 KB per file
Naming: Use descriptive keywords
```

## 3. Videos

**Title**: "ABC Analysis for Business Central - Product Overview"
**Duration**: 60-90 seconds
**Purpose**: Quick introduction to the app

**Script Outline**:
```

0:50-0:75 - Features (quick visuals)

- XYZ demand variability
- Powerful reporting
- Multi-language support

0:75-0:90 - Call to Action
"Start your 30-day free trial today. No credit card required.
Available now on Microsoft AppSource."
```

**Visual Requirements**:
- Show actual app interface
- Smooth transitions
- Professional voiceover
- Background music (subtle)
- On-screen text for key points
- End with clear CTA

### Video 2: Feature Deep Dive (Optional)
**Title**: "ABC Analysis - Complete Walkthrough"
**Duration**: 2-3 minutes
**Purpose**: Detailed feature demonstration

**Content**:
1. Opening ABC Worksheet
2. Setting parameters
3. Running analysis
4. Viewing classifications
5. Generating reports
6. Interpreting results
7. Taking action

### Video Specifications
```
Format: MP4, MOV, or WMV
Resolution: 1920×1080 (1080p) minimum
Aspect Ratio: 16:9
Frame Rate: 30 fps minimum
Audio: Clear narration, 128 kbps AAC
Bitrate: 5-10 Mbps
Subtitles: Recommended (SRT file)
Hosting: YouTube or Vimeo (provide URL)
```

### Video Best Practices

**Production Quality**:
- Professional voiceover (native speaker)
- Clear screen recordings
- Smooth cursor movements
- No typos or errors in demo
- Consistent pacing
- Good audio quality (no background noise)

**Content**:
- Start with the problem/pain point
- Make the customer the hero (not your company)
- Show real value quickly
- Include call to action
- Keep it concise
- Add captions/subtitles

**Technical**:
- Record at higher resolution (1080p or 4K)
- Use screen recording software (Camtasia, OBS)
- Edit professionally
- Add intro/outro branding
- Optimize for web streaming
- Test on multiple devices
