## Quick Start Checklist

### Before You Begin
- [ ] Read **01-AppSource-Submission-Guide.md** completely
- [ ] Create Microsoft Partner Network account
- [ ] Enroll in Commercial Marketplace program
- [ ] Register Object IDs and prefix (already done: 73030575-73031574, GMO)

### Legal Documents (Week 1)
- [ ] Customize **03-Privacy-Policy-Template.md**
- [ ] Customize **04-End-User-License-Agreement.md**
- [ ] Have legal counsel review both documents
- [ ] Publish Privacy Policy at https://www.gmsoft.co.uk/privacy_statement/
- [ ] Publish EULA at https://www.gmsoft.co.uk/abc_eula/

### User Documentation (Week 1-2)
- [ ] Review **05-User-Guide.md**
- [ ] Add actual screenshots from your extension
- [ ] Customize for your implementation
- [ ] Publish at https://www.gmsoft.co.uk/abc_help/
- [ ] Test all links work

### Marketing Assets (Week 2)
- [ ] Read **02-Marketing-Assets-Guide.md**
- [ ] Create logos (4 sizes: 48×48, 90×90, 216×216, 255×115)
- [ ] Create screenshots (5 images at 1280×720)
- [ ] Script and record product video (60-90 seconds)
- [ ] Create supporting PDFs (product brochure, quick start guide)
- [ ] Write marketing copy (app description, search summary)

### Technical Preparation (Week 2-3)
- [ ] Run AppSourceCop validation on your .app file
- [ ] Test in BC sandbox environment
- [ ] Verify all objects use GMO prefix
- [ ] Verify all objects in ID range 73030575-73031574
- [ ] Test in multiple BC versions (26.0+)
- [ ] Create permission sets (GMO ABC ADMIN, GMO ABC USER)

### Partner Center Setup (Week 3)
- [ ] Complete Partner Center enrollment
- [ ] Submit tax information (W-9 or W-8)
- [ ] Set up payout account (bank details)
- [ ] Configure publisher profile

### Create Offer (Week 3-4)
- [ ] Follow **01-AppSource-Submission-Guide.md** Section 3
- [ ] Create offer with ID: abc-analysis-gmsoft
- [ ] Complete Offer Setup tab
- [ ] Complete Properties tab
- [ ] Complete Offer Listing tab (use copy from Marketing Assets Guide)
- [ ] Upload logos and screenshots
- [ ] Add video URL
- [ ] Configure pricing plans (Basic, Professional, Enterprise)
- [ ] Upload .app file to Technical Configuration
- [ ] Review all sections

### Submit for Validation (Week 4)
- [ ] Click "Review and Publish"
- [ ] Verify all sections complete (green checkmarks)
- [ ] Submit for Microsoft validation
- [ ] Wait for validation results (2-5 business days)

### Certification (Week 5-6)
- [ ] Address any validation feedback
- [ ] Wait for manual certification (3-7 business days)
- [ ] Respond to any Microsoft questions promptly

### Go Live! (Week 6)
- [ ] Receive approval notification
- [ ] Offer goes live within 4 hours
- [ ] Verify listing on AppSource
- [ ] Test installation in clean BC environment
- [ ] Monitor analytics dashboard

### Post-Launch (Ongoing)
- [ ] Set up support processes (reference **06-Support-Documentation.md**)
- [ ] Monitor customer reviews and feedback
- [ ] Respond to support inquiries per SLA
- [ ] Track analytics in Partner Center
- [ ] Plan marketing and promotion
- [ ] Schedule regular updates

## Tips for Success

### Do's ✓
- Start with legal documents first (longest lead time for review)
- Create high-quality screenshots with real-looking demo data
- Test your .app file thoroughly before submission
- Respond to Microsoft feedback quickly
- Monitor analytics after launch

### Don'ts ✗
- Don't use placeholder text in AppSource listing
- Don't include customer data in screenshots
- Don't skip legal review of Privacy Policy and EULA
- Don't publish without testing in clean BC environment
- Don't ignore customer reviews after launch
