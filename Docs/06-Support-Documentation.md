## Troubleshooting

### No Data in Worksheet

**Symptoms**: ABC Worksheet is empty after calculation

**Causes**:
- No sales in date range
- Incorrect date filter format
- Missing permissions

**Solutions**:
1. Verify date filter: Use format MM/DD/YYYY..MM/DD/YYYY
2. Extend date range to last 12 months
3. Clear location filter
4. Check Item Ledger Entries for sales data
5. Verify user has GSO ABC USER permission

---

### Slow Performance

**Symptoms**: Analysis takes more than 5 minutes

**Causes**:
- Large dataset (>10,000 items)
- Wide date range
- Complex filters

**Solutions**:
1. Narrow date range to 12 months
2. Filter by item category or location
3. Run during off-peak hours
4. Contact support for Enterprise performance optimization

---

### Classification Errors

**Symptoms**: All items in one class, or unexpected results

**Causes**:
- Incorrect thresholds
- Wrong value basis
- Data quality issues

**Solutions**:
1. Verify thresholds sum to 100%
2. Check value basis (Sales Amount vs Quantity)
3. Update item costs
4. Post all pending sales invoices
5. Remove outlier items temporarily

---

### Report Generation Fails

**Symptoms**: Error when running reports

**Causes**:
- Filters too restrictive
- No classified data
- Permissions issue

**Solutions**:
1. Clear all filters
2. Run ABC calculation first
3. Verify report permissions
4. Try different report format (PDF vs Excel)
